# بوابة العلاونة للصرافة

بوابة ويب عربية لإدارة حسابات الموظفين، الموافقات، الحضور والانصراف، حالة الدوام، مؤشرات العمل اليومية، المهام، إشعارات الإنجاز، تقييم الأداء والرواتب.

تتضمن نسخة العرض تسجيل عمليات التحويل وتصريف العملات والمحافظ، مع بحث بالموظف والنوع والفترة، وتصدير CSV لآخر 200 عملية محمّلة. يسجّل النظام نسبة التنفيذ المحسوبة من المبلغين المدخلين، ويعرض للمدير سجل الإجراءات، والحضور، وحسابات الموظفين، والرواتب الشهرية المسجلة. أعداد العمل اليومية مشتقة من العمليات المسجلة بدلاً من إدخالها يدوياً. لا تجمع شاشة العمليات أسماء العملاء أو أرقام هوياتهم أو هواتفهم أو معلومات حساباتهم. إيقاف موظف من لوحة المدير يؤرشف حسابه ويمنع دخوله، مع إبقاء سجلاته محفوظة لأغراض المراجعة.

## حدود الاستخدام الحالي

هذا المشروع نموذج تشغيلي أولي لإدارة الموظفين وتسجيل عمليات داخلية، وليس نظاماً مالياً أو نظام صرافة معتمداً. لا يوفّر أسعار صرف مركزية أو اتصالاً ببنوك أو محافظ أو أنظمة تحويل، ولا ينفذ التسوية أو إقفال الصندوق أو معالجة النقد. نسبة التنفيذ في سجل العملية محسوبة من المبلغين المسجلين ولا تمثل سعر سوق أو سعراً معتمداً. لا يوجد حالياً فصل بين الفروع أو صلاحيات حسب الفرع، ولا رفع ملفات فعلي؛ يمكن حفظ رابط HTTPS مرجعي فقط.

قبل استخدامه في شركة أو مع أموال أو بيانات حقيقية، يلزم تصميم واعتماد التكاملات المالية، وفصل الفروع والصلاحيات، ومراجعة أمنية مستقلة، وخطة نسخ احتياطي واستعادة، وتحديد متطلبات الامتثال والخصوصية مع الجهة المختصة. لا تستخدم نسخة العرض المجانية لإدارة رواتب أو معاملات حقيقية.

## النشر على GitHub وخدمة استضافة

1. ارفع محتويات هذا المجلد إلى مستودع GitHub خاص؛ لا ترفع ملف `.env` أو أي أسرار.
2. أنشئ قاعدة PostgreSQL لدى مزود الاستضافة، ثم نفّذ محتوى `schema.sql` مرة واحدة على قاعدة البيانات.
3. أنشئ خدمة Node.js من مستودع GitHub، وحدد أمر التشغيل `npm start` وإصدار Node.js 20 أو أحدث.
4. أضف المتغيرات الواردة في `.env.example` ضمن إعدادات الخدمة السرية. أنشئ `SESSION_SECRET` عشوائياً قوياً، واختر اسم مستخدم وكلمة مرور مدير طويلة وفريدة.
5. اربط `DATABASE_URL` بقاعدة PostgreSQL وفعّل TLS، ثم انشر الخدمة.
6. عند أول تشغيل ينشأ حساب المدير «سامي أبو علي» من متغيرات البيئة. بيانات دخوله لا تُحفظ في ملفات المشروع ولا تُرسل للمتصفح.

## نسخة عرض مجانية عبر Render

المستودع يتضمن `render.yaml` لنسخة عرض مجانية. من لوحة Render اختر **New > Blueprint**، واربط مستودع `absimoh/alaawneh-exchange-staff-portal` والفرع `main`. عند طلب الإعدادات السرية، أدخل اسم مستخدم مدير وكلمة مرور مؤقتة قوية. ينشئ الخادم الجداول تلقائياً عند تشغيله الأول، وتستخدم الخدمة HTTPS وجلسات آمنة.

هذه نسخة عرض فقط. قاعدة Render المجانية محدودة وتنتهي بعد 30 يوماً، والخدمة قد تتوقف عند عدم الاستخدام؛ لا تستخدمها للرواتب أو بيانات الموظفين الحقيقية. لا تشارك حساب المدير؛ بعد العرض غيّر كلمة المرور أو أوقف الخدمة.

يفضل رفع المستودع كخاص لأن المشروع يحتوي واجهة داخلية، حتى مع عدم وجود أسرار فيه. لا تضع كلمات المرور في Issues أو ملفات README أو سجل Git.

## التشغيل المحلي (اختياري)

- ثبّت Node.js 20+ وPostgreSQL.
- نفّذ `schema.sql` على قاعدة فارغة.
- انسخ `.env.example` إلى `.env`، وضع بيانات PostgreSQL وكلمة مرور المدير و`SESSION_SECRET` حقيقية.
- شغّل `npm install` ثم `npm start` وافتح `http://localhost:3000`.

## الصلاحيات والسلوك

- تسجيل الموظف ينشئ حساباً غير مفعل؛ لا يمكنه الدخول قبل موافقة المدير.
- المدير فقط يستطيع تفعيل الحسابات وتعديل الرواتب والتقييم وإسناد المهام.
- كلمات المرور تُخزّن بصيغة bcrypt، والجلسات محفوظة في PostgreSQL عبر ملفات تعريف ارتباط HttpOnly وSameSite Strict.
- المهام المنجزة ترسل إشعاراً في لوحة المدير. حالات الاجتماع والاستراحة يغيّرها الموظف صراحة؛ لا توجد محاكاة عشوائية.
- عند تسجيل خروج الموظف أو إغلاق الصفحة يُسجل الانصراف تلقائياً؛ وإذا تعذر إرسال طلب الإغلاق، يكتشف الخادم الجلسة غير النشطة بعد دقيقتين من آخر تحديث.
- تُحفظ جلسات الحضور المتعددة ومؤشرات التحويل/التصريف/المحافظ يومياً، مع ترحيل آمن لسجل الحضور السابق. هذا تسجيل حضور عبر الويب وليس جهاز بصمة بيومترياً.
- المشروع يتطلب خدمة Node.js وقاعدة PostgreSQL؛ ملف HTML وحده أو استضافة صفحات ثابتة فقط لا يوفران المصادقة أو قاعدة البيانات.

## تنبيه الملفات

يمكن للمدير إرفاق PDF أو DOCX أو XLSX أو صورة PNG/JPEG بحجم أقصى 5 ميغابايت. تحفظ المرفقات في PostgreSQL وتتاح فقط للمدير أو الموظف المكلف عبر جلسة الدخول. التخزين محدود بسعة قاعدة البيانات المجانية؛ استخدم خدمة تخزين ملفات خاصة قبل تشغيل إنتاجي واسع.
